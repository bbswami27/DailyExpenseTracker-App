# Daily Expense Tracker v1.8.0

यह project केवल GharBudget-v1.7.0-Reports-ExpenseEdit.zip से बनाई गई अलग copy है।
किसी बाद वाले Ghar Budget project/version को बदला नहीं गया है।

## मुख्य बदलाव

- Notification में Add Expense और Add Income quick-action buttons जोड़े गए हैं।
- Quick action login/PIN के बाद सीधे संबंधित entry form खोलता है।
- Android 13 और उसके बाद के versions के लिए notification permission जोड़ी गई है।
- App का दिखाई देने वाला नाम अब **Daily Expense Tracker** है।
- Drawer में **Currency** विकल्प जोड़ा गया है।
- 12 currencies उपलब्ध हैं: INR, USD, EUR, GBP, AED, SAR, CAD, AUD, SGD, JPY, CNY और NPR।
- चुनी हुई currency device पर save रहती है।
- Amount entry, dashboard, expense/income history, budget, savings, reports और exports में चुनी currency लागू होती है।
- Version: **1.8.0** (versionCode 14)

## Android Studio

ZIP extract करें और GharKharch-v1.7.2 folder को Android Studio में खोलें।
Gradle Sync पूरा होने के बाद app run या APK build करें।
