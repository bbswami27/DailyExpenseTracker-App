# Daily Expense Tracker — Play Store Listing

## Short description
आय, खर्च, बजट, bills और shopping lists का आसान घरेलू हिसाब।

## Full description
Daily Expense Tracker आपके घर की income, daily expenses, monthly budgets, shopping lists और savings goals को एक स्थान पर व्यवस्थित करता है। Hindi/English item search, multi-item bills, bill photo/PDF, category-wise reports, custom date filters और छह महीने की rate comparison उपलब्ध हैं। Email login, PIN और supported devices पर fingerprint protection आपके account को सुरक्षित रखते हैं।

## Release checklist

- Privacy policy में `YOUR_SUPPORT_EMAIL` बदलें और public HTTPS URL पर host करें।
- Firebase Authentication और Storage enable करें।
- `firebase-storage.rules` deploy करें।
- Play Console Data Safety form में email, financial info और uploaded files declare करें।
- Android Studio: Build > Generate Signed App Bundle or APK > Android App Bundle.
- नई private upload keystore बनाएँ और उसकी सुरक्षित offline backup रखें।
- Phone screenshots: Dashboard, Add Expense, Reports, Shopping List और Security.
