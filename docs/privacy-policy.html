Daily Expense Tracker – Privacy Policy

Last updated: 26 August 2026

Daily Expense Tracker घरेलू आय, खर्च, बजट, shopping lists और savings goals को व्यवस्थित करने वाला personal finance app है।

हम कौन-सा data लेते हैं

  • Login के लिए email address और Firebase user ID.
  • User द्वारा दर्ज income, expenses, items, budgets, shopping lists और goals.
  • यदि user चुने, तो bill image/PDF.
  • PIN और biometric preference device पर रहती है; fingerprint data app को प्राप्त नहीं होता।

Data का उपयोग

Data केवल app features, user-wise separation, backup और restore के लिए उपयोग होता है। इसे advertising के लिए बेचा नहीं जाता।

Storage और security

Local data Room database में और cloud backup authenticated Firebase user के private path में रखा जाता है। Internet transmission encrypted connection से होती है।

User control

User entries edit/delete कर सकता है, backup बना सकता है और account/data deletion के लिए developer से संपर्क कर सकता है।
