# Daily Expense Tracker — 7 Language Support

इस build में English, हिंदी, বাংলা, ಕನ್ನಡ, मराठी, ગુજરાતી और ਪੰਜਾਬੀ शामिल हैं।

- Menu में `Language / भाषा` खोलकर भाषा चुनें।
- चुनी हुई भाषा device पर save रहती है।
- App की fixed UI labels translate होती हैं।
- User द्वारा लिखे गए shop, item, category और description नाम अपने मूल रूप में रहते हैं।
- Camera और Gallery/PDF bill attachment दोनों उपलब्ध हैं।

Version: 1.4.0 (5)
